## Посты пользователей

Так как задача предполагала реализацию за 1 час с использованием ИИ, я сфокусировался на быстром прототипировании UI.

**Процесс разработки:**

1. Данные постов были извлечены вручную и структурированы в формат `JSON` с помощью **ChatGPT**.
2. Базовая верстка компонентов (UI, похожий на LinkedIn с использованием Tailwind CSS) сгенерирована с помощью **Claude 4.5**.
3. Добавлена минимальная интерактивность на React (открытие/скрытие блока комментариев, счетчики).

> **Примечание по архитектуре:**
> Архитектура проекта намеренно упрощена (без настройки роутинга и глобальных стейт-менеджеров). Главной целью было уложиться в обозначенный тайминг и продемонстрировать навык быстрого создания **MVP** (Minimum Viable Product).
